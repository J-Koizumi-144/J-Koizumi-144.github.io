Daily Math Puzzle 2026/11/25

Original Post on X

English

The main line has one or more stations in a row, with a track joining each pair of consecutive stations. Any number of additional tracks may branch off from each station on the main line. Each such track leads directly to a station served only by that track. Let \(n\geq 2\) be the total number of stations, and assign the numbers \(1\) through \(n\) to the stations, using each number once. The fare for a track is the larger of the two numbers at its ends minus the smaller. Prove that the stations can be numbered so that all the fares are different.

日本語

本線には一つ以上の駅が一直線に並び，隣り合う駅どうしが線路で結ばれている． 本線の各駅からは，さらに何本かの線路が延びていてもよい． それぞれの先には，その線路だけが通じる駅が一つある． 駅の総数を \(n\)（\(n\geq 2\)）とし，各駅に \(1\) から \(n\) までの番号を重複なく一つずつ付ける． 各線路の料金は，両端の駅の番号のうち，大きい方から小さい方を引いた値とする． すべての線路の料金が互いに異なるように番号を付けられることを示せ．
