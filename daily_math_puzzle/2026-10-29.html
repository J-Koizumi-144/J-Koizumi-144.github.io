Daily Math Puzzle 2026/10/29

Original Post on X

English

Let \(n\) be an integer with \(n\geq2\). Tile a rectangle with \(n\) rows and \(2n-2\) columns using \(1\times2\) tiles aligned with the grid, leaving no gaps or overlaps. Tiles may be placed vertically or horizontally. Find all \(n\) for which this can be done so that every row contains a different number of horizontal tiles.

日本語

\(n\) を2以上の整数とする． 縦 \(n\) マス，横 \(2n-2\) マスの長方形を，\(1\times2\) のタイルで，マス目に沿ってすき間や重なりなく敷き詰める． タイルは縦向きにも横向きにも置いてよい． 各行にある横向きのタイルの枚数が，どの2行でも異なるようにできる \(n\) をすべて求めよ．
